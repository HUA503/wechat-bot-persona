# 目标群数据快照

本目录中的 `group-backup-2026-11-14.zip` 是 2026-11-14 导出的目标群数据快照。仓库公开，文件中的聊天记录和群成员标识可被任何访问者查看。

压缩包包含：

- `group-chat.json`：从机器人所用微信账号读取的目标群消息记录，包含 1,287 条记录及消息元数据。图片、视频等消息仅包含记录和引用，不包含媒体文件本身。
- `memory.sqlite3`：仅保留目标群数据的机器人记忆数据库快照。导出时没有已保存的记忆记录。

如需在机器人中恢复记忆，请先停止机器人并备份现有的 `cache/memory.sqlite3`，再将压缩包中的数据库放到该路径。聊天记录 JSON 是归档文件，机器人不会自动把它作为对话历史加载。
